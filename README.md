# Device_gui — 液体颗粒检测上位机

基于 **C++17 / Qt6 / OpenCV** 的工业视觉检测上位机:加载颗粒图像,完成图像处理流水线(灰度 → 阈值 → 形态学 → 轮廓提取),统计颗粒数量、粒径分布并导出检测结果。

> 个人项目,目标是构建一个可演示、可测试、结构清晰的工业检测软件(通信/采集与产品化仍在迭代中)。

---

## 功能

### 图像分析流水线
- 加载图像(文件选择 + 显示)
- 灰度化 → 阈值分割(阈值可调)→ 形态学开/闭运算(核大小可调)
- 轮廓提取与颗粒计数(面积过滤可调)
- 颗粒几何量:等效直径、周长/圆度、面积(平均/最大/最小)
- **粒径分布**:D10 / D50 / D90、span、标准差
- 21 点累积分布曲线
- **CSV 导出**:参数、统计量、分布曲线(含 UTF-8 BOM,Excel 可直接打开)

### 界面与交互
- Qt Widgets 界面 + QSS 样式
- 菜单栏 / 状态栏 / 事件处理
- 图像显示(自适应缩放)

### 工程特性
- **多线程**:分析任务在 worker 线程执行(`moveToThread`),界面不阻塞
- **任务生命周期**:线程安全退出(`quit`/`wait`/`deleteLater`)
- **防重入**:分析进行中禁用触发按钮并显示状态
- **算法模块独立**:`Analyzer` 抽为静态库,与界面解耦
- **单元测试**:QTest + CTest,用合成图标定"已知输入 → 已知输出"
- **CMake 构建**:AUTOMOC/AUTOUIC/AUTORCC,目标级依赖管理

### 通信(完成 v16—v18)
- `tools/sim_device`:**本地 TCP 模拟设备**(QTcpServer 监听 8888),替代真实硬件的测试对手
- **上位机客户端**:`QTcpSocket` 连接/断开 + 状态显示
  - 信号驱动:connected / disconnected / readyRead / errorOccurred
  - 用 `state()` 判断当前连接状态,按钮复用一个(连接 ⇄ 断开)
- **自定义协议**:**4 字节长度头(大端,值 = 消息体字节数)+ 消息体**;接收端用"缓冲区 + `while` 循环拆包"处理**粘包/半包**(已用合成数据验证两种边界)
- **可靠性**:失败计数 + 主动连接有限重试 + **掉线自动重连**(标志位区分"用户主动断开"与"意外掉线");通过**故障注入**验证(不启动设备 / 中途杀掉 / 重启恢复)

## 构建与运行

**依赖**:Qt 6、OpenCV 4.x、CMake ≥ 3.16

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="<opencv>/build"
cmake --build build
```

或在 Qt Creator 中打开 `CMakeLists.txt`,选择 Kit 后直接构建运行。

**运行测试**:
```bash
cd build && ctest --output-on-failure
```
